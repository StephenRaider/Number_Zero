# Runtime decals

32 transparent vector-authored runtime decals, exported at up to 1024 x 512.
Full-resolution PNGs, vector originals and reference photographs stay in the
experiment workspace. Runtime PNGs contain no baked lighting or source photos.

`catalog.txt`: stable ID | label | single-ink flag | PNG filename.
Existing IDs retain their order to preserve saved selections and placements.
The rejected dragon designs remain excluded.

Base graphics contain the main design and, where present, its large sponsor
wordmark. Small sponsor rows, secondary logos and number panels are removed
from every base design, including Mint Club Racer and the racing liveries.
Directional racing stripes remain mirrored for right-side placement and run
top to bottom. Honeycomb has a solid vertical left edge and diagonal right fade.

Independent additions:
- `20_sponsor_overlay`: sponsors around the perimeter with a clear centre.
- `21_sponsor_strip`: a single bold sponsor row.
- Abstract race marks A, B and C, each plain single-ink and boxed black-on-white with
  a thick black border. Boxed variants keep their black/white colours.

Suggested stack: base graphic on layer 1, sponsor strip on layer 2, number on
layer 3. The top layer draws last. All can move/scale/rotate independently.

Race mark glyphs intentionally use broken loops and offset strokes rather than readable digits. Original numeric IDs remain stable for save compatibility.
